Creditor Residence, Refinancing, and Monetary Transmission
Szymon Cichoń, Uniwersytet Ekonomiczny w Katowicach

Pakiet zawiera dane i kod do odtworzenia wyników artykułu. Po rozpakowaniu
wejdź do katalogu sovereign-debt-transmission. W tym katalogu znajdują się
run.py, requirements.txt oraz podkatalogi data i src.

Obliczenia były wykonywane w Pythonie 3.12. W terminalu, w katalogu projektu,
uruchom kolejno:

    python3 -m venv .venv
    source .venv/bin/activate
    python -m pip install -r requirements.txt
    python run.py all

Polecenie all wykonuje całą analizę: przygotowuje panele z danych źródłowych,
estymuje modele, liczy wnioskowanie i tworzy tablice oraz wykresy. Na końcu
sprawdza zgodność danych i obliczeń. Etapy można też uruchamiać osobno:

    python run.py data
    python run.py estimate
    python run.py exhibits
    python run.py check

Należy zachować tę kolejność przy pierwszym uruchomieniu. Później, po zmianie
wykresu, wystarczy ponowić exhibits. Zmiana modelu wymaga ponownego estimate,
a następnie exhibits i check. Program przerywa pracę po wykryciu błędu;
wówczas warto zacząć od ostatniego komunikatu w terminalu.

Dane źródłowe są w data/raw. Ich adresy, identyfikatory i sumy kontrolne
zapisano w data/sources.csv. Pliki data/macro_sources.json oraz
data/monetary_instruments.csv opisują wybór szeregów makroekonomicznych
i instrumenty użyte do pomiaru niespodzianek monetarnych. Data/processed
zawiera przekształcone obserwacje; etap data odtwarza je z oryginałów.

Po uruchomieniu powstają katalogi results i output. W results są oszacowania,
kowariancje, wybrane kontrole, klucze obserwacji i wyniki testów. Najważniejsze
pliki to ml_lp.csv dla projekcji lokalnych, ml_var.csv dla VARX oraz
ml_var_matched_lp.csv dla porównania na tej samej próbie. Pełniejsze zapisy,
w tym wyniki pośrednie potrzebne do wnioskowania, mają rozszerzenie JSON.
Tablice w formacie LaTeX trafiają do output/tables, a wykresy PDF do
output/figures. Wyniki nieprecyzyjne i nieistotne również są zapisywane.

Opis metod znajduje się w docs/methods.md, a definicje zmiennych i ich
jednostki w docs/variables.md. Kod estymacji jest w src; kolejność wywołań
można prześledzić w run.py. Projekcje lokalne, LASSO i VARX są zaimplementowane
bezpośrednio, z wykorzystaniem algebry numerycznej NumPy i SciPy.
